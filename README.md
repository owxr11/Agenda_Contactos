# Agenda de Contactos
Agenda de contactos sencilla hecha con HTML, CSS y JavaScript.

## Características
- Agregar contactos con nombre y teléfono
- Eliminar contactos
- Buscar contactos por nombre

## Tecnologías
- HTML
- CSS
- JavaScript

## Cómo usarlo
1. Clona el repositorio
   ```
   git clone https://github.com/owxr11/Agenda_Contactos
   ```
2. Abre index.html en tu navegador
